# Project_3
Symulacja obiektu inercyjnego + PID (pełna pętla sprzężenia zwrotnego w software)

Potencjometr (Lewy pin) -> GND
Potencjometr (Środkowy pin) -> A0
Potencjometr (Prawy pin) -> 3.3V
Dioda LED (Anoda +) -> D5
Rezystor (220Ω) -> szeregowo z LED -> Między D5 a LED lub LED a GND.
Dioda LED (Katoda -) -> GND
LCD SDA -> D2
LCD SCL -> D1
